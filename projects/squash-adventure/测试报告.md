# 倭瓜射手大冒险 · 测试报告

产品版本：1.0.0。交付内容包括 Android APK、电脑试玩、完整源码、美术资源、构建工具入口、测试源码和运行记录。

## 环境与构建

- Windows 11 / JDK 25；Android API 35 / Build Tools 35.0.0。
- Android 原生验证：雷电模拟器 Android 14，1920 × 1080，指定 `emulator-5554`。
- 包名 `com.squash.adventure`，最低 Android 6.0，无原生 ABI 库限制。
- 应用完成编译、签名、ZIP 对齐与模拟器安装；原生测试程序独立于试玩 APK。

## 游戏机制

`GameModelTest` 通过 216032 次机制与数值断言，覆盖二连跳、三跳拦截、落地复位、暂停恢复、十秒武器时限、拾取、固定击杀分数、范围伤害、防重复计分、结算、最高分保存、重开清理和 UI 输入拦截。

长期验证包含 30 分钟自动操作与自然失败重开，以及 10 分钟连续场景生成。连续生成检查会移走接近角色的威胁，用于隔离验证时间、速度、生成和对象回收，不代表真实玩家生存时间。

## 路线与难度

`ChallengeBalanceTest` 的 13 项验收通过：短刺单跳、长刺延后二跳、低顶贴地、乱跳失败、地形不可射毁、暂停和重开，以及零输入、固定连点和按路线操作三种策略的对照。

30 个种子中，零输入与固定连点均会失败；按路线操作的程序均通过开场，15 个达到 120 秒检查上限。程序读取精确坐标，不用于代表普通玩家水平。

`SpeedProgressionTest` 通过 216012 次断言，覆盖速度连续、单调、关键倍率、暂停恢复和重开。正常生成路线从 0、30、60、120、180、300 秒进度开始，每档 8 个种子，各运行 28 秒，48/48 通过路线样本检查。

完整结果见 `evidence/build.log`。

## Android 原生检查

`AndroidSmoke` 的 25 项检查通过，覆盖：

- 首页、开始、触屏跳跃、二连跳、三跳拦截和暂停按钮。
- 实际帧循环冻结与继续、Activity 暂停与恢复。
- 高处武器收取、暂停冻结、十秒到期、玉米范围击杀。
- 接触失败、结算重开、荆棘跳跃、低顶贴地和悬藤失败提示。
- 正常生成路线中的持续触屏操作、实体数量与响应状态。
- 一分钟进度附近的连续加速与约 1.7 倍速度显示。

单项条件检查会放置测试对象，再通过实际输入事件与 Choreographer 帧循环执行。正常路线检查保留正常生成、碰撞、射击和拾取，测试程序只安排触屏时机。加速检查将时间安排到 59.8 秒，再推进实际帧循环，不以真实等待一分钟替代该条件检查。

结果见 `evidence/android-checks.log`；截图包括首页、二连跳、暂停、机枪、大炮、结算、长刺、低顶和速度 HUD。桌面绘制截图与 Android 原生截图分别标注。

核对内容包括应用版本 1.0.0、界面和文档命名一致、文件引用有效、APK 与 JAR 可读取、ZIP 可解压及 SHA-256 文件校验。交付包只描述成品功能与验证结果。
