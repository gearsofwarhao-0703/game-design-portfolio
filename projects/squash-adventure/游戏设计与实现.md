# 倭瓜射手大冒险 · 游戏设计与实现

版本：1.0。类型：横版自动前进、弹跳射击与无限跑酷。

## 核心循环

倭瓜射手自动小幅弹跳前进，并从嘴部向前射击。玩家观察前方路线，安排第一跳和第二跳，清除不同高度的敌人、越过地形并拾取高处武器。击杀带来分数，成功穿越带来险地计数；身体接触敌人或危险地形后进入结算，可直接重开。

## 操作和战斗

| 项目 | 规则 |
| --- | --- |
| 起跳 | 点击屏幕或按空格；空中允许第二次跳跃，落地复位 |
| 基础攻击 | 自动每 0.43 秒发射豌豆，命中一次即可消灭敌人 |
| 玉米大炮 | 持续 10 秒，每 0.78 秒发射抛物线炮弹，爆炸半径 195 虚拟像素 |
| 豌豆机枪 | 持续 10 秒，每 0.105 秒发射一颗豌豆 |
| 道具 | 位于约离地 305 / 310 像素的气泡中，需要判断跳跃高度与路线 |
| 武器替换 | 收取武器立即切换，并获得完整 10 秒时间；到期恢复基础攻击 |
| 得分 | 每消灭一只敌人固定 +100，爆炸逐只计分 |
| 失败 | 身体接触存活敌人、荆棘或悬藤；透明图边缘采用收紧的碰撞范围 |
| 暂停 | 冻结物理、敌人、地形、生成时钟、武器时间和难度进度 |

角色的跳跃高度会改变子弹发射高度，因此空中攻击与落点安全需要一起判断。敌人保持 Idle 表现：骷髅分体轻摆，幽灵悬浮，不主动追逐玩家。

## 路线挑战

| 路线 | 操作重点 |
| --- | --- |
| 短荆棘 | 看准前沿起跳，避免过早落在刺上 |
| 长荆棘 | 接近第一跳顶点再按第二次，延长滞空 |
| 两拍起跳 | 跨过第一片短刺，落地后安排下一跳 |
| 低顶悬藤 | 保持贴地，经过出口后再考虑补给 |
| 高低夹击 | 荆棘上方配幽灵，选择空中开火或绕高 |
| 火力补给 | 在长刺上方取武器，为后续密集怪群做准备 |
| 低顶接短刺 | 从等待切换到起跳，判断出口与尖刺间距 |
| 尖刺接力 | 短刺后接长刺，重新安排第二跳 |
| 空中猎手 | 长刺与较高幽灵同时影响跳跃和射击高度 |
| 喘息补给 | 整理操作节奏，决定是否为高处道具起跳 |

开场按固定次序引入规则，随后选择不同路线组合。每段保留落地恢复窗口，障碍宽度与段内间距按预计到达时的速度生成。荆棘与悬藤不能被射击或爆炸消除。

## 渐进难度

镜头跟随主角，前进速度通过地面、敌人、道具和地形相对角色的运动体现。速度提高会缩短可观察和反应的时间。

| 存活时间 | 虚拟像素 / 秒 | 开局倍率 |
| --- | ---: | ---: |
| 开局 | 300 | 1.00 |
| 15 秒 | 330 | 1.10 |
| 30 秒 | 390 | 1.30 |
| 60 秒 | 510 | 1.70 |
| 90 秒 | 600 | 2.00 |
| 120 秒 | 675 | 2.25 |
| 180 秒 | 750 | 2.50 |
| 后期 | 平滑接近 900 | 平滑接近 3.00 |

各关键点之间采用缓动，避免速度阶跃。暂停不推进难度时间，重开恢复开局速度。路线组合与恢复间隔共同增加压力，同时保留二连跳可通过的距离。

## 美术和反馈

使用题目提供的主角、三种嘴部、弹道、骷髅头身、幽灵、武器气泡、背景和 UI 图片，共 31 张直接使用的美术素材。地面由题目纹理交替镜像循环；云层、远景、地面和花粉采用不同速度。

角色有起跳伸展、落地压缩、后坐和枪口效果；敌人有轻摆、闪白、消散、粒子和浮分。玉米爆炸包含冲击波、震动与音效。地形以同色系程序化图形绘制，标注单跳、二连跳或贴地提示。结算显示具体死因和操作建议。

音效和 8 秒循环配乐由脚本合成。HUD 展示得分、最高分、距离、穿越险地数量、剩余跳跃、武器倒计时和速度倍率。

## 技术实现

游戏规则由不依赖平台的 Java 模型实现，Android Canvas 与桌面 Java2D 共用场景绘制接口。Android 使用 Choreographer 跟随刷新率绘制，以固定 120 Hz 更新逻辑；切后台时暂停并清除累积时间，避免恢复时跳帧推进。

跳跃采用按下事件，长按不会连续触发；落地前 120 ms 内可缓存一次起跳。子弹命中先于同帧身体碰撞处理。离屏实体与过期特效及时清理，爆炸粒子数量上限为 420。最高分与声音设置保存在本地，不依赖网络、账号或广告服务。
