# 姚力翀 · 游戏设计作品集

收录关卡与任务设计、玩法机制原型，以及小组游戏项目。每个项目页提供设计资料、预览和试玩入口。

## 个人作品

| 项目 | 设计内容 | 试玩 |
| --- | --- | --- |
| [归钟寺 · 最后一响](projects/gui-zhong-temple/) | 第三人称动作关卡。探索古寺、操作铸钟工坊的机关，并利用钟声破解首领的双锁机制。 | Windows |
| [这戏来真的](projects/real-take/) | 叙事任务原型。从屋内调查到仓库战斗、驾车追逐、证据调查与交接，包含完整任务和独立教学入口。 | Windows |
| [倭瓜射手大冒险](projects/squash-adventure/) | 横版自动射击跑酷。用单跳和二连跳选择路线及射击高度，并通过限时武器应对不同地形。 | Android、桌面 Java |
